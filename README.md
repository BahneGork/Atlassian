# Atlassian

An interactive atlas of **Erukana**, the world of our RPG campaign.

The map is the navigation: pins and regions open panels about each place, with links to the full notes on the published campaign notes site.

- Static site (Leaflet), hosted on GitHub Pages
- Atlas data is curated from the campaign notes; see [`docs/project-plan.md`](docs/project-plan.md)

## Status
Design phase. See the plan for scope and decisions.
